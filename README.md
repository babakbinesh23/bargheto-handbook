# هندبوک تعاملی برقتو

**Bargheto Handbook — a Persian RTL, full-stack employee onboarding and internal content-management application.**

این مخزن سورس هندبوک سازمانی برقتو است؛ محیطی برای معرفی سازمان، هیئت‌مدیره، واحدها، نقش‌ها، سیاست‌ها و مسیر آشنایی کارکنان. برخلاف مخازن لندینگ، یک سایت HTML ساده نیست و بخش سرور، احراز هویت، مدیریت داده و فایل دارد.

**نسخه مستندشده بسته انتقال:** `V62` (اطلاعات منشأ در [EXPORT_MANIFEST.json](migration/EXPORT_MANIFEST.json) ثبت شده است.)

## قابلیت‌های برنامه

- رابط فارسی و راست‌به‌چپ با صفحه ورود و بخش‌های سازمانی
- پنل ادمین، مدیریت واحدها و دسترسی مسئولان
- ویرایش محتوای متنی، تصاویر، کارت‌ها و ترتیب نمایش
- مدیریت نقش‌ها، نشست‌های ورود و سطح دسترسی
- APIهای محتوایی، اعلان‌ها، آپلود فایل و داده‌های مهاجرتی
- الگوی اتصال به Cloudflare D1 و R2

## فناوری‌ها

| بخش | فناوری |
| --- | --- |
| رابط و سرور | Next.js 16 + React 19 + TypeScript |
| اجرای Cloudflare | Vinext، Vite، Wrangler و Cloudflare Workers |
| دیتابیس | Drizzle ORM و Cloudflare D1-compatible binding (`DB`) |
| رسانه‌ها | Cloudflare R2-compatible binding (`BUCKET`) |
| طراحی | CSS / Tailwind |
| تست و بررسی | Node.js test runner، ESLint، اسکریپت‌های اعتبارسنجی |

`"private": true` در `package.json` برای جلوگیری از انتشار اشتباهی بسته در npm است؛ **مخزن GitHub فعلاً Public است**.

## نصب و اجرای محلی

**پیش‌نیاز:** Node.js `>=22.13.0` و محیط سازگار با Bash / Linux؛ برخی اسکریپت‌ها از `flock` و GNU `timeout` استفاده می‌کنند.

```bash
npm ci
npm run dev
```

آدرس را مطابق خروجی Vite در ترمینال باز کنید. اجرای محلی ممکن است بدون Bindingهای شبیه‌سازی‌شده یا پیکربندی سرویس‌های D1/R2، همه قابلیت‌های مدیریت داده را ارائه نکند.

بررسی‌ها:

```bash
npm run lint
npm run build
npm test
```

**توجه:** در `package.json`، دستور `npm test` ابتدا Build را اجرا می‌کند؛ اجرای جداگانه `npm run build` قبل از آن اختیاری است.

## ساختار مخزن

- `app/` — مسیرها، رابط React، پنل مدیریت، ورود و APIها
- `lib/` — مجوزها، مدیریت نشست و منطق مشترک
- `db/` و `drizzle/` — اتصال پایگاه‌داده و مهاجرت‌ها
- `public/` — تصاویر و دارایی‌های عمومی
- `worker/`، `vite.config.ts` — بخش‌های اجرای Cloudflare/Vinext
- `scripts/`، `tests/` — ابزارهای Build و تست
- `migration/` — دستورالعمل و داده‌های نمونه انتقال
- `release/bargheto-handbook-V62-export.zip` — بسته خروجی نسخه V62
- `README-SITES.md` — مستندات زیرساخت اولیه Sites/Vinext؛ توضیح محصول در همین README اولویت دارد

## انتقال داده و میزبانی

به ترتیب [راهنمای انتقال](migration/MIGRATION_GUIDE_FA.md)، [Manifest خروجی](migration/EXPORT_MANIFEST.json) و [داده‌ها](migration/data/README_FA.md) را بررسی کنید.

- بسته V62 شامل Snapshot قابل‌انتقال محتوا و تصاویر ارجاع‌شده است.
- داده‌های کامل احراز هویت، مجوزهای کاربران، نشست‌های فعال و گزارش‌های مدیریتی در این بسته انتقالی کامل نیستند.
- برای استقرار واقعی باید دیتابیس، Bucket، احراز هویت و تنظیمات دامنه مقصد را دوباره پیکربندی کنید.
- `lib/authorization.ts` فعلاً دارای شناسه مالک از پیش تنظیم‌شده و رفتار توسعه محلی است. قبل از استقرار عمومی، آن را برای محیط مقصد و مدل اعتماد به Headerها بازبینی کنید.

## امنیت و حریم خصوصی

**مهم:** مخزن عمومی است و محتویات `migration/data/` و فایل‌های منتشرشده را هر کسی می‌تواند مشاهده کند. Snapshot محتوا شامل اطلاعات متنی سازمانی و نام‌های نمایش‌داده‌شده است؛ قبل از انتشار گسترده‌تر، مجوز افشای داده‌ها و تصاویر را بررسی کنید. یک README یا تست موفق به‌تنهایی اثبات‌کننده عدم وجود داده حساس یا آسیب‌پذیری نیست.

هرگز `.env`، توکن‌های API، کوکی و Session، کلیدهای سرویس، بکاپ خصوصی D1/R2 یا رمزهای مدیر را Commit نکنید. راهنمای [گزارش امنیتی](SECURITY.md) را ببینید.
