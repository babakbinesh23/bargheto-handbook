# هندبوک برقتو

هندبوک تعاملی شرکت برقتو برای معرفی سازمان، هیئت‌مدیره، پرسنل، واحدها، قوانین و مسیر آشنایی کارمند جدید.

نسخه انتقالی فعلی: `V62`

## امکانات

- صفحه ورود ادمین و مسئولین
- دسترسی ویرایش مجزا برای مسئول هر واحد
- مدیریت متن، تصویر، ترتیب و اندازه کارت‌ها
- بارگذاری تصویر و تنظیم نقطه تمرکز
- مدیریت کاربران و مجوزها
- اعلان تغییرات بخش‌ها
- دیتابیس مشترک و فضای ذخیره تصاویر

## اجرای محلی

پیش‌نیاز: Node.js نسخه `22.13.0` یا جدیدتر

```bash
npm ci
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
```

این پروژه HTML ثابت نیست و برای اجرای کامل به Node.js، دیتابیس سازگار با Cloudflare D1 و فضای فایل سازگار با R2 نیاز دارد.

## محدودیت نسخه انتقالی

حساب مسئولین، رمزهای هش‌شده، مجوزهای کاربران، نشست‌های فعال و گزارش کامل مدیریتی داخل مخزن قرار نگرفته‌اند. پیش از انتقال نهایی باید خروجی کامل D1 و R2 از میزبان فعلی گرفته شود.

## امنیت

هیچ Token، Cookie، Session یا فایل محیطی محرمانه داخل مخزن قرار نگرفته است. این مخزن عمومی است و محتوای آن برای همه قابل مشاهده خواهد بود.
